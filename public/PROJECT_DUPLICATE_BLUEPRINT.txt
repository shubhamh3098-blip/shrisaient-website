2. PROJECT TECH STACK & ARCHITECTURE (प्रोजेक्ट तंत्रज्ञान)
--------------------------------------------------------------------------------
- Frontend: React 19 + TypeScript + Vite + Tailwind CSS
- Animation: Motion (Framer Motion v12)
- Icons: Lucide React
- Backend: Node.js + Express (Full-stack API proxy for Google Gemini AI)
- PWA: Vite PWA (Offline Service Worker, Installable Mobile Web App)
- Database & Sync:
  * Local: IndexedDB (Client-side offline-first persistence) + LocalStorage
  * Cloud: Google Cloud Firestore (Realtime sync & multi-device sync)
- AI Vision: Google Gemini 2.5 Flash / Gemini Multimodal for Purchase Invoice Scanning

6. HOW TO RUN / SETUP A FRESH COPY (नवीन डुप्लिकेट कसे सुरू करावे)
--------------------------------------------------------------------------------
स्टेप १: ZIP फाईल डाऊनलोड करून नवीन फोल्डरमध्ये Unzip करा:
   `unzip shri-sai-enterprises-clean-source.zip -d shri-sai-enterprises`
   `cd shri-sai-enterprises`

स्टेप २: आवश्यक लायब्ररी इन्स्टॉल करा:
   `npm install`

स्टेप ३: डेव्हलपमेंट मोडमध्ये ॲप चालवा:
   `npm run dev`
   (हे http://localhost:3000 वर सुरू होईल)

स्टेप ४: प्रॉडक्शन बिल्ड तयार करा:
   `npm run build`

स्टेप ५: प्रॉडक्शन सर्व्हर सुरू करा:
   `npm start`
